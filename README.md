# Bilklar

B2C-app för svensk privat övningskörning. Första versionen svarar på:

- **Vad ska vi träna på idag?**
- **Hur gick det, och vad bör vi träna på nästa gång?**

Detta repo har ännu inte produktkod. Den första artefakten är en draft-taxonomi för B-körkortets praktiska skills.

## Dokumentation

- [Skill Taxonomy v1](docs/domain/skill-taxonomy.md) — principer, källor, coverage och review
- [skill-taxonomy-v1.json](docs/domain/skill-taxonomy-v1.json) — maskinläsbar input till senare seed av `skills` / `skill_definitions`

Taxonomin är **Draft**. Den blir inte Canonical förrän efter separat review.
